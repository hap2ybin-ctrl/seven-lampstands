# 일곱 금촛대 — 이기는 자의 약속 매칭

요한계시록 2–3장의 일곱 교회와, 각 교회의 "이기는 자"에게 주신 약속을 짝지으면
그 교회의 등잔에 불이 켜지는 웹앱입니다. 일곱 등잔이 모두 켜지면 완성 화면이 나옵니다.

## 실행 방법

빌드나 설치가 필요 없습니다.

- **내 컴퓨터에서**: `index.html` 을 더블클릭해 브라우저로 엽니다.
- **휴대폰으로 나눠 쓰기**: 폴더의 파일 4개(`index.html`, `style.css`, `app.js`, `data.js`)를
  그대로 정적 호스팅(GitHub Pages, Netlify, 교회 홈페이지 서버 등)에 올리고 주소를 공유합니다.
- 인터넷이 없으면 제목 서체(Noto Serif KR)만 기기 기본 명조체로 바뀌고, 나머지는 그대로 동작합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 (시작 · 게임 · 완성 · 학습용 표) |
| `style.css` | 배경, 등대, 카드, 인쇄용 스타일 |
| `app.js` | 게임 로직, SVG 등대 그리기, 저장, 접근성 |
| `data.js` | 교회·약속·힌트·참고 문구 데이터 |

## 하는 방법

- 약속 조각 12장을 일곱 교회에 나누어 놓습니다. 조각을 누른 뒤 교회를 누르거나,
  조각을 교회 이름표·등잔으로 끌어다 놓습니다. 놓을 때는 맞는지 알려 주지 않습니다.
- 12장을 모두 놓으면 `맞는지 확인` 버튼이 나오고, 누르면 한꺼번에 판정합니다.
  그 교회의 조각을 **전부, 그리고 그것만** 넣은 교회만 불이 켜지고 장·절 배지가 붙습니다.
  - 틀린 교회에는 "n개가 맞지 않습니다"(잘못 들어간 조각의 수)만 알려 주고, 어느 조각인지는 알려 주지 않습니다.
  - 잘못 들어간 조각은 없는데 조각이 덜 들어간 교회에는 "조각이 모자랍니다"라고 알려 줍니다.
  - 틀린 교회의 조각은 그 자리에 남습니다. 조각을 눌러 카드 영역으로 되돌린 뒤 다시 놓고, 또 확인합니다.
- 교회에 놓은 조각은 끌어서 다른 교회로 바로 옮길 수 있습니다. 휴대폰에서는 조각을 꾹 눌렀다가 끌고,
  마우스로는 그냥 끕니다. 카드 영역으로 끌어다 놓으면 되돌아갑니다.
  - 오답 횟수는 확인할 때 틀린 교회 하나당 1번으로 셉니다.
- 같은 교회에서 2번 틀리면 그 교회에 `힌트` 버튼이 생깁니다. 힌트를 열면 약속이 몇 개인지와
  약속을 떠올리게 하는 단서가 나오고, 그 아래에 그 교회에 하신 말씀이 작게 나옵니다.
- 진행 상황은 브라우저에 저장되어 새로고침해도 이어집니다. `다시 하기`를 누르면 처음부터 다시 시작합니다.
- 효과음은 기본으로 꺼져 있고, 오른쪽 위 `효과음` 버튼으로 켭니다.

### 키보드

| 키 | 동작 |
|---|---|
| `Tab` | 교회 이름표 → 카드 순서로 이동 |
| `Enter` / `Space` | 카드 고르기, 교회에 놓기, 버튼 누르기 |
| `←` `→` `↑` `↓` | 카드끼리, 이름표끼리 이동 |
| `1` ~ `7` | 고른 카드를 그 번호의 교회에 놓기 |
| `Esc` | 고르기 취소 |

화면 낭독기는 정답·오답·힌트를 `aria-live` 영역으로 읽어 줍니다.
기기에서 "동작 줄이기"를 켜 두면 불꽃 흔들림과 흔들기 효과가 꺼집니다.

## 데이터 수정 방법

`data.js` 만 고치면 됩니다.

```js
{ id: "ephesus", name: "에베소", ref: "계 2:7", lampIndex: 0,
  promises: [{ id: "eph-1", text: "낙원에 있는 생명나무 과실" }],
  hint: "처음 사랑을 버렸느니라 (2:4)",
  clue: "에덴동산 한가운데 있던 것을 떠올려 보세요.",
  note: "",
  verseText: "" }
```

| 항목 | 설명 |
|---|---|
| `promises[].text` | 카드에 나오는 약속 문구. 정답 판정은 `id` 로 하므로 문구는 자유롭게 고쳐도 됩니다. |
| `promises[].id` | 조각마다 달라야 합니다. 조각을 더하거나 빼면 그 교회의 정답 개수도 함께 바뀝니다. |
| `lampIndex` | 등잔 위치. 왼쪽부터 0~6 이 한 번씩 나와야 합니다. |
| `clue` | 힌트를 열었을 때 크게 나오는 단서. 약속과 바로 이어지는 실마리를 적습니다. 비우면 `hint` 만 나옵니다. |
| `hint` | 단서 아래에 작게 나오는 "이 교회에 하신 말씀" |
| `note` | 학습용 표의 "참고 문구" 칸에만 나옵니다. 정답 판정에는 쓰지 않습니다. |
| `verseText` | 비워 두었습니다. 채우면 학습용 표의 약속 조각 아래에 본문이 함께 나옵니다. |
| `LAMP_LAYOUT` | `"menorah"`(가지 7개인 등대 하나, 기본값) 또는 `"seven-stands"`(따로 선 촛대 7개) |
| `CLOSING_VERSE` | 완성 화면 문구 |

고친 뒤 브라우저 개발자 도구의 콘솔을 열면 검증 결과가 한 줄로 나옵니다.

```
[일곱 금촛대] 데이터 검증 통과 — 조각 12개, 교회별 [1, 2, 2, 2, 2, 2, 1]
```

조각 수를 일부러 바꾸면 이 검증이 오류를 알려 줍니다. 그때는 `data.js` 의 `validateLampData()` 안에 있는
기대값(`EXPECTED`, 합계 12)도 함께 고쳐 주세요. 콘솔에서 `validateLampData()` 를 직접 불러 볼 수도 있습니다.

데이터 구조(카드 개수 등)를 바꾼 뒤 예전 진행 상황이 맞지 않으면 앱이 저장된 내용을 버리고 새로 시작합니다.

## 성경 본문 저작권 주의 사항

- 이 앱에는 **성경 본문이 들어 있지 않습니다.** 카드 문구는 약속의 내용을 짧게 요약한 표현이고,
  힌트의 단서는 본문을 풀어 쓴 설명이고, "이 교회에 하신 말씀"은 짧은 인용구와 장·절 표기입니다.
  단서 문구는 교회의 가르침에 맞게 `data.js` 의 `clue` 에서 고쳐 쓰세요.
- `verseText` 에 본문을 직접 넣을 때는 **쓰려는 번역본의 저작권과 이용 조건을 먼저 확인**하세요.
  개역개정, 새번역, 공동번역 등 대한성서공회 번역본과 그 밖의 현대어 번역본은 대부분 저작권이 있으며,
  웹에 올리거나 인쇄해 나눠 줄 때는 권리자의 허락이나 이용 안내에 따른 절차가 필요할 수 있습니다.
- 교회 안에서 화면으로만 쓰는 경우와, 누구나 볼 수 있는 주소에 올리는 경우는 조건이 다를 수 있습니다.
  공개 호스팅에 올릴 계획이라면 본문을 넣기 전에 꼭 확인하세요.
- 본문을 넣었다면 표 아래나 이 문서에 번역본 이름과 저작권 표시를 함께 적어 두는 것을 권합니다.
- 확인이 어려우면 `verseText` 는 비워 두고 장·절만 보여 주는 지금 상태로 쓰는 것이 가장 안전합니다.
